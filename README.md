# 考勤处理工具

把从考勤系统导出的「原始打卡流水」按人按天整理成「一人一行、每天一列」的标准化考勤表。

## 文件说明

| 文件 | 作用 |
|------|------|
| `check_process.py` | 核心处理逻辑（修复了 `clear_time` 去重，并模块化供 GUI/CLI 共用） |
| `app.py` | tkinter 图形界面 |
| `requirements.txt` | Python 依赖清单 |
| `build_windows.bat` | Windows 一键打包脚本，生成 `.exe` |
| `3.xls` | 标准化模板示例（含员工姓名表头） |
| `4天.xls` | 原始打卡流水示例 |

## 输入文件要求

**原始打卡流水**（如 `4天.xls`）：三列 `姓名 / 日期 / 当天打卡时间`，同一人的 N 天记录连续排列，无表头。

**标准化模板**（如 `3.xls`）：第一行为日期表头 `1~31`，第二列是员工姓名，脚本据此定位每个员工写到第几行。

## 一、在 Windows 上生成 .exe（关键步骤）

> ⚠️ `.exe` 只能在 Windows 上打包生成，mac/Linux 无法跨平台生成 Windows 可执行文件。

1. 在 Windows 电脑上安装 **Python 3.8+**（勾选 *Add Python to PATH*）。
   下载：<https://www.python.org/downloads/>
2. 把整个项目文件夹拷到 Windows 电脑。
3. 双击运行 `build_windows.bat`，等待打包完成。
4. 打包产物在 `dist\考勤处理工具.exe`，**单独这一个文件**拷到任何 Windows 电脑即可双击运行，无需安装 Python。

如果 `.bat` 脚本执行失败，可手动在命令行执行：

```bat
pip install -r requirements.txt
pyinstaller --noconfirm --onefile --windowed --name 考勤处理工具 app.py
```

## 二、使用方法

1. 双击 `考勤处理工具.exe` 打开界面。
2. 依次选择：原始打卡流水 `.xls`、标准化模板 `.xls`、输出文件路径，填写考勤天数。
3. 点击「开始处理」，日志区会实时显示进度。
4. 完成后到输出路径查看生成的考勤表。

## 三、命令行用法（可选）

不打开图形界面，直接命令行运行：

```bash
python check_process.py 4天.xls 3.xls 4 --out-file 结果.xls
```

参数：`<流水.xls> <模板.xls> <天数> [--out-file 输出.xls]`

## 四、本次修复内容

`clear_time` 函数原来在打卡条数 > 4 时，`if/else` 两个分支返回值相同，**没有真正去重**，只靠前面的 `set` 去掉完全重复项，同一小时内多次刷脸仍会全部保留。

修复后：打卡条数 > 4 时，按「小时」分组，**同一小时只保留最早一次打卡**，合并重复刷脸。例：

```
输入: 07:26 07:28 12:17 14:24 14:25 17:31   （6条，07点和14点各有两次）
输出: 07:26 12:17 14:24 17:31               （4条，每小时保留最早）
```

同时增强了健壮性：模板中找不到姓名时不再崩溃，而是记录警告并跳过该人。
